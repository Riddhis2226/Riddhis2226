### Consumer360
**Enterprise-grade customer analytics platform**

**Problem:** The original build used a naive 5-segment RFM model, a mathematically flawed CLV formula, and a churn model with label leakage inflating its AUC to 1.0.

**Solution:** Rebuilt from scratch on Medallion architecture (Bronze → Silver → Gold) over the UCI Online Retail dataset, with an 11-segment RFM model, BG/NBD + Gamma-Gamma CLV modeling, and a corrected churn pipeline — served via FastAPI, orchestrated with Prefect, modeled in dbt, covered by 50 pytest tests.

`Python` `FastAPI` `dbt` `Prefect` `Docker` `Azure` `pytest`
